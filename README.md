# Memory Game
A browser-based memory matching game built with JavaScript.

## About
Memory Game is a classic card matching game. The goal is to find all 8 matching pairs using as few moves as possible.

## Features
- 16 cards with 8 matching pairs

- Random card shuffling

- Move counter

- Matched pairs counter

- Delayed closing of mismatched cards

- New Game functionality

- Victory modal

- Leaderboard with saved results

- Top 10 results stored in Local Storage

- Responsive design for desktop and mobile devices

## Technologies
- HTML5

- CSS3

- JavaScript

- Local Storage

## How to play
1. Click on a card to reveal it.

2. Click on another card to reveal the second card.

3. If the cards match, they remain open.

4. If the cards do not match, they close after a short delay.

5. Match all 8 pairs to win.

6. Your result is automatically added to the leaderboard.

## Deployment

To run the project locally:
1. Clone the repository:
`git clone https://github.com/alena-js/memory-game.git`
2. Open the project folder:
`cd memory-game`
3. Open `index.html` in a web browser
